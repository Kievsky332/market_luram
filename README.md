# market_luram

Прототип интерфейса маркетплейса "Luram" (Tired-root). Демонстрационная веб-страница, воссоздающая визуальный стиль и базовую структуру современного интернет-магазина.

## Описание проекта

Этот проект представляет собой фронтенд-прототип магазина. Он демонстрирует навыки адаптивной верстки, работы с CSS-анимациями и базовой интерактивностью на стороне клиента. Проект не включает серверную часть, базу данных или реальную систему оплаты, а служит визуальной демонстрацией интерфейса.

---

## Стек технологий

- **HTML5** — семантическая разметка страницы и структуры товаров
- **CSS3** — стилизация, адаптивный дизайн и визуальные эффекты
- **JavaScript (ES6+)** — базовая интерактивность элементов интерфейса (например, обработка кликов или динамические обновления)

---

## Запуск локально

Проект является полностью статическим и не требует установки зависимостей (Node.js, npm и т.д.).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/market_luram.git
   ```
2. Перейдите в проект
   ```bash
   cd market_luram
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
